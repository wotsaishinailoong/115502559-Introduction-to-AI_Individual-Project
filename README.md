# 英文系統音訊 → 繁體中文字幕

Windows 10／11 桌面程式，自動選取預設喇叭／耳機的 WASAPI loopback 音源，將電腦播放的英文語音轉成英文與繁體中文字幕。適用於影片、線上課程及一般電腦播放音訊。無須 API 金鑰；音訊在本機處理，不儲存錄音或傳送至雲端。

## 安裝與使用

1. 安裝 **Python 3.11 64 位元**（[python.org](https://www.python.org/downloads/)），保留 Python Launcher／pip／Tcl/Tk 選項。
2. 下載此儲存庫並解壓縮，雙擊 `setup.bat` 安裝依賴。套件下載需要網路，PyTorch 等依賴可能佔用數 GB 空間；建議至少 8 GB RAM。
3. 雙擊 `run.bat` 開啟程式。選擇正在使用的喇叭或耳機，按「開始」。預設會自動選取 Windows 預設播放裝置，不需開啟麥克風。
4. 首次執行會下載 Whisper 與中譯模型。等待狀態顯示「正在聆聽」後，播放英文內容。
5. 字幕會分段出現。按「停止」結束，使用「匯出雙語 SRT」儲存字幕。重新開始會清除上一輪字幕，程式會先詢問確認。

更換耳機或 Windows 預設播放裝置後，請先停止，按「重新偵測」選取音源，再開始。程式只擷取選定裝置的播放內容，不會錄製麥克風；該裝置上所有應用程式的聲音都可能被辨識。

## 本機模型與行為

- 辨識：`faster-whisper` 的 `base.en`，CPU INT8，英文語音活動偵測（VAD）。
- 翻譯：`Helsinki-NLP/opus-mt-en-zh`，CPU 推論，再以 OpenCC `s2twp` 轉換繁體用語。
- 模型快取：`%LOCALAPPDATA%\LocalSubtitles\models`。首次下載需要存取 Hugging Face 及其檔案下載服務；快取完整後可離線使用。若需強制禁止模型庫連網，可在啟動前設定 `HF_HUB_OFFLINE=1`。
- 每約 4 秒送出一段音訊；顯示延遲還包含辨識、翻譯時間，依 CPU 效能而異。這不是逐字即時翻譯。
- 最多保留兩段待處理音訊，跟不上時會略過最舊的一段並提示。切段可能切開句子，翻譯亦可能有誤，尤其是人名、口音、背景音樂及多人同時說話。
- 按停止後會丟棄尚未完成的音訊；目前模型運算或下載可能要等到結束才完成停止。關閉視窗也會等待背景作業收尾。
- SRT 時間從開始擷取算起，保留略過片段造成的時間間隔。若需要與影片對齊，請從影片起點同步開始或於字幕工具中調整時間偏移。

## 疑難排解

- **找不到裝置**：確認 Windows 有啟用的喇叭／耳機，按「重新偵測」。遠端桌面、特殊驅動或受保護內容可能無法擷取。
- **沒有字幕**：確認音源與播放內容所在裝置一致，並播放清楚的英文語音。靜音、純音樂或很短的片段可能被 VAD 略過。
- **下載模型失敗**：確認網路／代理允許 `huggingface.co` 及其重新導向的模型下載網域（例如 `*.hf.co`），再重新開始。不要停用 TLS 驗證。
- **擷取失敗／裝置拔除**：停止，重新連接裝置並按「重新偵測」。
- **處理緩慢**：關閉其他大量使用 CPU 的程式。此版本預設 CPU，沒有要求 NVIDIA 顯示卡。
- **安裝失敗**：確認使用 Python 3.11 x64。命令列可用 `py -3.11 --version` 確認；詳細錯誤會留在安裝視窗。

## 開發與驗證

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m live_subtitles.app
```

自動化測試驗證立體聲轉單聲道、48 kHz／44.1 kHz 重取樣、異常樣本處理、佇列超載行為及雙語 SRT 時間格式，不會下載模型。

目前開發環境為無圖形桌面的 Linux 雲端機器，且模型下載遭網路政策阻擋。因此 Windows WASAPI、GUI 與真實模型端到端翻譯仍需在 Windows 實機驗證，不能把自動化測試通過視為這些功能已通過實機測試。

Windows 驗收步驟：播放一段已知英文句子，確認英文辨識與繁體中譯；測試靜音、停止／重新開始、切換耳機，以及匯出的 SRT 能在字幕播放器載入。完成首次下載後，斷網再開始一次以確認模型快取可用。
